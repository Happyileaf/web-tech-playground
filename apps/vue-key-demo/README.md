# Vue Key 可视化实验室（vue-key-demo）

## 1. Demo 介绍

`vue-key-demo` 是一个基于 Vue 3 + Composition API + TypeScript 构建的**列表渲染 `key` 差异可视化实验台**。

本实验不通过静态动画伪造 Diff 结果，而是让四种 `key` 策略在同一套 Vue 3 运行时下同步渲染真实的 `<UserCard>` 组件列表，并通过组件生命周期钩子（`onMounted` / `onUpdated` / `onUnmounted`）与组件内部局部状态（`ref`），真实采集和对比节点复用、创建、销毁与状态错位情况。

## 2. 演示目标

直观对比 `v-for` 在以下四种 `key` 策略下的真实差异：

1. **未配置 `key`**：Vue 采用就地更新策略（`patchUnkeyedChildren`），按位置复用节点，容易导致组件内部状态与数据身份错位。
2. **使用 `index` 作为 `key`**：`index` 仅代表当前位置而非数据身份，当列表发生头部删除、头部插入或重排时同样会造成状态错位。
3. **使用唯一但不稳定的值作为 `key`**：每次渲染都会生成新 `key`，虽然唯一但无法建立新旧 VNode 对应关系，导致组件反复卸载与重建、内部状态丢失。
4. **使用唯一且稳定的 ID 作为 `key`**：帮助 Vue 在新旧 VNode 之间建立精准的身份映射，实现正确的节点复用、移动、创建与销毁，内部状态始终跟随数据身份。

## 3. 涉及的技术知识

- Vue 3 列表渲染（`v-for`）
- 虚拟 DOM（VNode）与 Diff 算法（`patchUnkeyedChildren` / `patchKeyedChildren`）
- 组件实例生命周期追踪（`onMounted` / `onUpdated` / `onUnmounted`）
- 组件内部非受控状态与 Props 身份分离现象

## 4. 环境要求

- Node.js `>= 20`
- pnpm（或 npm / yarn）

## 5. 安装方式

在独立迁移目录或当前应用目录中安装依赖：

```bash
pnpm install
```

（若使用 npm，可执行 `npm install`。）

## 6. 启动方式

```bash
pnpm dev
```

构建与类型检查：

```bash
pnpm build
```

## 7. 使用说明

1. **统一操作区**：支持删除第一项、删除中间项、头部插入、中间插入、反转顺序、随机排序、修改数据、模拟父组件重渲染以及重置；所有操作同步作用于四种策略。
2. **自定义状态验证**：每个人员卡片内的备注输入框保存在 `UserCard` 组件内部 `ref` 中。可直接修改任意卡片的备注，或点击快捷标记按钮后执行列表操作，观察状态跟随、错位或丢失现象。
3. **执行模式切换**：
   - **即时执行**：操作立即生效并实时更新四种策略的 DOM 统计与变化记录。
   - **逐步执行**：将一次操作拆解为「操作前 → 数据变化 → 新旧 VNode 对比 → 组件更新 → 更新完成」五个阶段进行教学演示。
4. **五大经典实验**：可一键载入文档设计的五个典型实验场景并对照观察要点。

## 8. 相关注意事项

- 本 Demo 完全运行在浏览器本地，不依赖任何后端接口或外部数据库。
- 逐步执行模式中的“新旧 VNode 对比”步骤用于教学解释 key 匹配规则，实际 DOM 复用/创建/销毁统计均来自 Vue 3 真实组件实例生命周期反馈，而非预先写死的模拟数据。
